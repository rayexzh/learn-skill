# 学习 Skill · 中文说明

[返回首页](README.md) · [English](README.en.md)

这个 Skill 用简明中文带你一步一步学习。你需要亲自答题、解释和做任务，AI 负责讲解、反馈和调整难度。

## 安装

下载仓库后，把 `zh/learn` 整个文件夹复制到你的 Codex 技能目录：优先使用 `CODEX_HOME/skills`；没有设置 `CODEX_HOME` 时，使用用户目录下的 `.codex/skills`。

如果那里已经存在 `learn`，先备份并检查差异，再决定是否替换。英文版也叫 `learn`，只能选择一个版本。重新开始会话后，确认技能列表中出现“学习 Skill”。不同 Agent 的技能目录和发现方式请以各自当前文档为准。

## 调用

```text
用 $learn 带我学【主题】。
我现在的基础是【基础】，每天有【时间】。
最后我希望能独立完成【任务】。
```

- 普通知识和具体技能：默认精简路线。
- 陌生行业或需要研究争议的问题：可以说“完整十步”。
- 学习过程中：直接说“太难了”“只复习”“继续”“暂停并给我续学记录”。

## 怎样知道自己学会了

分别检查：提示下完成、独立完成、新题能用、隔几天还会。AI 会等你的实际答案或产物；没有答题就不会宣布你已经掌握。

## 边界

不承诺学习快十倍，也不把 AI 模拟专家意见或自评分当作事实证明。十步法不是每次都必须完整执行。复习时间可以调整；Skill 不会自动创建提醒，也没有自带永久记忆。

原论文与学习研究链接在 [Skill 文件](zh/learn/SKILL.md) 中。来源支持部分设计，不证明整套流程的效果。
