# 学习 Skill · Learn by practicing

[中文说明](README.zh-CN.md) · [English](README.en.md)

把“看懂 AI 的答案”推进到“自己能完成任务”的互动学习 Skill。

An interactive learning skill that checks what you can do independently, not just what you can follow in an AI explanation.

## Choose one language / 选择一个语言版本

| Version | Skill source | Invocation |
| --- | --- | --- |
| 中文 | [zh/learn/SKILL.md](zh/learn/SKILL.md) | `$learn` |
| English | [en/learn/SKILL.md](en/learn/SKILL.md) | `$learn` |

两个版本使用同一个名称，请选择一个安装，不要同时安装。两版教学流程一致，默认解释语言不同。

Both versions share the name `learn`. Install one language at a time. They implement the same workflow with different default explanation languages.

## Start / 开始

```text
用 $learn 带我学习 Excel 数据透视表。
我是初学者，每天有30分钟，目标是独立汇总销售数据。
先走精简模式，每次一道题，等我回答再继续。
```

```text
Use $learn to teach me Excel pivot tables.
I am a beginner with 30 minutes per day.
My goal is to summarize a sales spreadsheet independently.
Use the short route and wait for my answer to each question.
```

## Two routes / 两条路线

- **精简 / Short:** goal → example → practice → feedback → explanation → independent transfer → delayed review.
- **完整 / Full:** perspectives → disagreements → brief → evidence → resources → ladder → core task → retrieval → explanation → reference sheet, followed by independent transfer and delayed review.

Tenfold speed is not promised. The whole workflow has not been experimentally validated. Sources support specific components and are listed in each skill.
